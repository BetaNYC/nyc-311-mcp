# nyc-311-mcp

An [MCP](https://modelcontextprotocol.io/) server that lets an AI assistant answer
questions about NYC 311: the city-services calendar, emergency and weather alerts,
311 service-request lookup, and more. Built by [BetaNYC](https://beta.nyc).

- **Using the released version?** Install steps are in the
  [README](https://github.com/BetaNYC/nyc-311-mcp#readme).
- **Want to try what is coming next?** See [Beta MCPs](beta/index.md): unreleased
  builds you can test before they ship, and how to tell us what you find.

This is an independent, community-built project. It is not affiliated with,
endorsed by, or an official product of the City of New York.
