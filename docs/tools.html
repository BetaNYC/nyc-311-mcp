Every tool

nyc-311-mcp has 23 tools. You don't need to know their names. Ask your question in plain English and your AI assistant picks the tool. Below is what each one does, a few things to try, and a replay of a real question and answer.

If this is an emergency, or if you think this is an emergency, call 911. Every answer from every tool ends with that line. Danger detection is a best effort and it will miss some emergencies.

The demos are real answers, captured November 9, 2026, with BoardStat data as of November 9, 2026, with 311 requests through November 8. We shortened them to fit, and left out home addresses. Your numbers will be newer.

Help reporting a problem

Tell it what's wrong in your own words. It finds the City's own 311 article for that problem, the agency that handles it, and every way to report it. It can also write a short report for you to paste in. It never files anything. You do that yourself.

how_to_report

New in 1.2.0Needs a free 311 API key

Describe the problem the way you'd tell a neighbor. It searches the City's 311 articles and gives back the best match: the article title and link on 311 Online, the agency, the 311 problem type, what the City says happens next, and every way to report it. Give it your district and it also tells you how often people there reported the same thing. If your description sounds dangerous, the first line tells you to call 911. It catches a lot, but it will miss some emergencies, so don't count on it for that.

Try asking:

  • “There's a pothole on my block that keeps getting bigger. How do I report it?”
  • “My upstairs neighbor plays loud music every night.”
  • “No heat in my apartment.”
  • “Overflowing trash can and a broken bench in the park.”

draft_311_report

New in 1.2.0Needs a free 311 API key

Writes a short report you can paste into 311 Online: the problem, where, when, and what you saw. It doesn't fill in anything you didn't tell it. If something is missing, it marks the gap and asks you. It links the right 311 page, lists the City's Problem Detail options (from a 2024 City list, so they may be out of date), and says what happens after you report. It won't write a draft when it sees danger. It tells you to call 911 instead. It doesn't send anything or fill in any form.

Try asking:

  • “Help me write a 311 report about a pothole at 7th Avenue and 9th Street in Brooklyn. It's been there since last week.”
  • “Draft a 311 report about a broken streetlight on my corner.”

list_311_categories

New in 1.2.0Needs a free 311 API key

Browse 311's own topics, the same ones on 311 Online, when a match looks wrong or you just want to see what 311 covers. Pick a topic to list its articles, 20 at a time.

Try asking:

  • “What kinds of things can I report to 311?”
  • “Show me 311's noise articles.”

Your community district or Council district

These read the files BoardStat builds every night from NYC Open Data, with 311 requests from 2020 on. Every answer links to the BoardStat page with the same district, dates and problems, so you can check the numbers yourself. No API key needed.

find_district

New in 1.2.0No key needed

Type an address the way you normally would. It tells you the community district and the Council district, and how many 311 requests have been made there since 2020.

Try asking:

  • “What community board and Council district is 250 Broadway in?”

district_summary

New in 1.2.0No key needed

The big picture for one district: how many requests, how many aren't closed, how long they take to close, and the top problems. For each top problem, it compares the district's share with the borough's and the city's.

Try asking:

  • “Give me a summary of 311 in Brooklyn Community Board 6.”
  • “What does 311 look like in Council District 7 this fiscal year?”

top_problems

New in 1.2.0No key needed

The most-reported problems in a district for any period, next to the same days a year earlier.

Try asking:

  • “What were the top 311 complaints in Brooklyn 6 in the last 30 days?”
  • “Top problems in Council District 39 last fiscal year?”

problem_trend

New in 1.2.0No key needed

One problem, month by month, in one district, with the same days a year earlier next to each month.

Try asking:

  • “How has residential noise in Brooklyn 6 changed month to month this year?”

agency_response

New in 1.2.0No key needed

For each agency: how many requests, how many are closed, and the median and average days to close. Remember that closed doesn't mean fixed.

Try asking:

  • “How fast do agencies close requests in Council District 39?”
  • “Which agency is slowest in Bronx 1 this fiscal year?”

still_open

New in 1.2.0No key needed

Requests that aren't closed yet, oldest first, with how many days each has been open and a count by agency. The City doesn't define its statuses, so we explain each one and label the explanation as ours.

Try asking:

  • “What 311 requests in Brooklyn 6 are still open?”
  • “Which agency has the most open requests in Queens 1?”

top_addresses

New in 1.2.0No key needed

The addresses with the most requests in a district, with each one's most common problem. You can narrow it to one problem.

Try asking:

  • “Which addresses in Brooklyn 6 get the most 311 requests?”
  • “Where are the most heat complaints in Bronx 5?”

address_history

New in 1.2.0No key needed

Every request at one address since 2020, newest first, with the status explained and the agency's own resolution text. It's the closest thing to looking up a request when you don't have its number.

Try asking:

  • “What's been reported at 1 Centre Street?”
  • “Any open requests at City Hall?”

find_requests

New in 1.2.0No key needed

Every request in a district, newest first, a page at a time. Filter by problem, agency, or status, including the City's own statuses like Pending.

Try asking:

  • “Show me the newest street-condition requests in Brooklyn 6.”
  • “List DOT requests in Manhattan 3 that are Pending.”

boardstat_link

New in 1.2.0No key needed

Makes a BoardStat link with your district, dates, problem, agency, and status already set, so you can open the map and charts yourself.

Try asking:

  • “Give me a BoardStat link for residential noise in Brooklyn 6, last 90 days.”

boardstat_status

New in 1.2.0No key needed

How fresh BoardStat's data is, and whether last night's build ran late. Ask this when a number looks off.

Try asking:

  • “How fresh is BoardStat's data?”

The Local Law 47 reports

In 2005, Local Law 47 (Gale A. Brewer) required monthly 311 reports from the City, written into Charter § 1075. Two of those reports were repealed in 2023. We rebuilt all three from NYC Open Data. They are BetaNYC rebuilds, not the City's official reports, and every answer says so. No API key needed.

ll47_service_request_report

New in 1.2.0No key needed

Rebuilds the monthly report on requests for service, formerly Charter § 1075(b): totals by category, agency, and status, and the average and median days to close, for a month and for the fiscal year to date. Citywide, by borough, or for one district.

Try asking:

  • “Rebuild the Local Law 47 monthly 311 report for Brooklyn 6.”
  • “Run the § 1075(b) report for Queens for October.”

cb_monthly_list

New in 1.2.0No key needed

The list that Charter § 1075(d), still law, says community boards should get: one district's requests for a month, every older request still unresolved, and the ones closed since. Comes in pages, or as a CSV.

Try asking:

  • “Give Brooklyn Community Board 6 its monthly list of 311 requests for October.”
  • “Same list for Staten Island 1, as a CSV.”

ll47_directory_assistance_report

New in 1.2.0No key needed

Calls answered by 311 agents, by topic, for a month and the fiscal year to date, formerly Charter § 1075(c). This one is limited, and the answer says so: the open data can't separate out directory-assistance calls, and its agency column is blank. NYC Open Data can be slow here, so the first full-year answer may take a few tries.

Try asking:

  • “How many calls did 311 agents answer in October, by topic?”

Today in the city

The City's own 311 calendar and status alerts. These were in 1.1.0, too.

get_calendar

Same as 1.1.0Needs a free 311 API key

Alternate side parking, trash and recycling collection, and schools, for a day or up to 90 days.

Try asking:

  • “Is alternate side parking in effect today?”
  • “Is trash pickup on schedule the week of Thanksgiving?”

get_status

Improved in 1.2.0Needs a free 311 API key

Whether Code Blue, a fire hydrant emergency, snow or ice, or an emergency management alert is in effect right now. The answer now says it in words.

Try asking:

  • “Is there a Code Blue tonight?”
  • “Is there a snow emergency on the streets?”

Look up a 311 request

Have a 311 number, like 311-12345678? These tell you where it stands, in words. The City sends a status code, and we translate it.

get_service_request

Improved in 1.2.0Needs a free 311 API key

Look up a request by its 311 number. You get the agency, the problem, the status in words, and the agency's own note about what it did. ZIP codes are removed.

Try asking:

  • “What happened with 311 request 311-17323508?”

get_service_request_list

Improved in 1.2.0Needs a free 311 API key

Several 311 numbers at once. Any number the City can't find is listed, so nothing quietly goes missing.

Try asking:

  • “Check these three 311 numbers for me: …”

About this server

Ask what changed in the server lately, or who built it. Every BetaNYC MCP server is getting these two tools; nyc-311-mcp is the first. They read the same list as the What's changed page. No API key needed.

whats_changed

New in 1.3.0No key needed

What changed in this server, newest first: new tools, data fixes, and corrections when an answer was wrong. You can ask for corrections only, or for changes since a date.

Try asking:

  • “What's new in the 311 server?”
  • “Has the 311 server ever corrected a wrong answer?”

about_betanyc

New in 1.3.0No key needed

Who built this server, where to report a problem with this server or ask for a feature, and links to BetaNYC's events, newsletter, and ways to get involved.

Try asking:

  • “Who made this 311 tool?”
  • “Where do I report a problem with the 311 server?”
